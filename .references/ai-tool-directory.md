## How to actually choose (the 3 questions)
1. **What's the job?** Hire for the job, not the hype. (You rarely need the "best" tool — you need the right one for this task.)
2. **Can the free option do it today?** Start free. Upgrade only when the free tool is the *measured* bottleneck, not before.
3. **Does it lock in your data?** Prefer tools you can export from / self-host (Obsidian, n8n, Ollama) for anything core.
