# Easy Italia Hub

Landing page della piattaforma **Easy Italia Hub** — guide burocratiche, assistente AI multilingua e community per la comunità srilankese in Italia.

## Stack
- HTML statico single-page
- Particelle 3D animate (canvas)
- Tema chiaro elegante (Playfair Display + Inter)
- Deploy su Vercel con header di sicurezza (CSP, HSTS, ecc.)

## Contenuti
- `index.html` — landing page
- `robots.txt` — direttive crawler (AI crawler consentiti per GEO)
- `sitemap.xml` — sitemap con hreflang (IT/EN/SI/TA)
- `vercel.json` — config hosting + security headers

## Deploy
Collegato a Vercel: ogni push su `main` ridistribuisce automaticamente.
